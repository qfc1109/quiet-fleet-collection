# 术语表

| 术语 | 定义 |
| --- | --- |
| 逻辑知识库 | 以一个 `project_id` 为隔离边界的问答资料范围。它是产品概念，不等于已经创建了某个外部平台的物理知识库。 |
| 负责人 | 对项目成员、纳入问答文件、外部数据共享和索引失败重试负责的网站用户。无负责人项目不能启用问答；负责人仅由后台管理员指定。 |
| 项目成员 | 通过 `project_member` 关系加入项目的用户。`VIEWER` 只读问答，`EDITOR` 可编辑项目文件；两者都可以查询已纳入问答的文件。成员管理和外部共享仅负责人可操作。 |
| 纳入问答 | 负责人对文件或目录执行的显式选择，表示该资料允许进入索引；默认关闭。 |
| 目录快照 | 负责人选择目录时记录的当前文件集合；以后新增文件不会自动纳入，必须再次显式选择。 |
| 敏感文件 | 密钥、证书、数据库、压缩包及其他被后端规则阻止外发或索引的文件。扩展名判断不是唯一依据，规则需结合路径和内容风险。 |
| 索引状态 | 文件在知识库流水线中的状态：待处理、索引中、可用、失败。 |
| 引用 | 回答所依据的来源信息，至少包含 `fileId`、`relativePath`、`quote` 和 `locator`。 |
| locator | 引用在原文中的定位信息。按格式可为 Markdown 行/标题、PDF 页码、Word 段落；无法定位时使用无精确定位标记。 |
| 临时多轮 | 页面内保留最近三组问答作为当前请求上下文，刷新或离开页面后不提供历史恢复。 |
| 外部服务 | 项目自身服务器之外的模型或知识库 API。发送前必须由负责人选择非敏感资料，并向用户展示数据去向。 |
| 自定义模型适配器 | 后端可配置的 OpenAI 兼容 REST 调用边界，承载 `baseUrl`、模型名、API Key、超时和额度；当前模型名为 `gpt-5.6-terra`，API Key 只通过被忽略的本地/部署配置注入。 |
| answerId | 单次回答的临时标识，用于提交反馈和去重，不代表保存了聊天正文。 |
| 回答反馈 | 用户对单个回答提交的“准确 / 不准确”判断。每个用户对同一回答只保留一次，反馈保存 `answerId`、`userId`、`vote`、`projectId`、`createdAt` 等元数据，不保存聊天正文。 |
| RAG | 先从项目资料中检索片段，再把片段交给生成模型组织回答的流程。 |
